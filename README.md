# Dhruthi-with-ink
Emotions embedded with ink
ಅವಳು ಅಳುಕಿಲ್ಲದವಳು
ಪರಿಸ್ಥಿತಿಯ ಕೈ ಗೊಂಬೆಯಾದವಳು 
ಹೋಸ್ಟಿಲಾಚೆ ಹೊಂಗನಸೊಂದು ಕಾದು ಕುಳಿತಿತ್ತು 
ಹೊಸ್ತಿಲಿನ ಒಳ ಬದಿಯಲ್ಲಿ ಗೃಹಿಣಿ ಎಂಬ ಜವಾಬ್ದಾರಿ ಕೈ ಬೀಸಿ ಕರೆದಿತ್ತು 
ಕಲಿತ ಕಲೆಗಳು ಒಲೆಯ ಮುಂದೆ ಕರಗಿದವು
ಮಾಡಿದ ಅಡುಗೆಗೆ ಬಂದ ಪ್ರಶಂಸೆಯಷ್ಟೇ ಅವಳ ಸಾಧನೆಯಾಗಿತ್ತು
ಹೊರ ಜಗತ್ತು  ಸ್ತ್ರಿ ಎಂಬ ಬಲೆಯ ಕಿಂಡಿ ಇಂದ ಮಾತ್ರವೆ ಕಾಣುತಿತ್ತು 
ಜನರ ಸಂಪರ್ಕ ಗುಡಿ ಗೋಪುರಗಳಲ್ಲಾಷ್ಟೇ ಸೀಮಿತವಾಗಿತ್ತು
ಉಡುಗೆ ತೊಡುಗೆ ಆಡಂಬರಗಳು ದರಿಕಾಣದೆ ಮಾಯವಾಗಿದ್ದವು
ಬದುಕು ಬಣ್ಣವಿಲ್ಲದೆ ಮಾಸಿತ್ತು ಇರುಳು ಕವಿದಿತ್ತು 
ಭರವಸೆಗಳ ದಾರಿ ಕಾಯುತ್ತಾ 
ಜವಾಬ್ದಾರಿಗಳ ಅನುಸರಣೆಯಲ್ಲಿ 
ಅವಳು ಎಲ್ಲೋ ಕಳೆದೆ ಹೋದಳು
